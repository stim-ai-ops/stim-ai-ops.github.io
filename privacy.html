プライバシーポリシー

本ツールは、利用者本人が自分の Google アカウントで許可した範囲（Gmail の閲覧、Google スプレッドシート・ドキュメント・ドライブ、Google アナリティクスの閲覧）のデータを、本人の業務の自動化のためにだけ使います。

  • 取得したデータは本人の端末と本人が管理する保存先にだけ置き、第三者へ販売・提供しません。
  • 広告や本人以外の目的には使いません。
  • 許可はいつでも Google アカウントの設定 から取り消せます。

Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
